```
YouTube URL → MCP Processor → get_transcript → Transcript → SummaryEngine → TLDR (LONGFORM)
```

## 🎯 **Как это работает**

### **Базовый сценарий:**
1. **Пользователь отправляет YouTube ссылку** в Telegram бот
2. **Бот определяет** доступность MCP процессора
3. **MCP процессор извлекает** video_id из URL
4. **Вызывается MCP сервис** `get_transcript` для получения транскрипта
5. **Транскрипт передается** в SummaryEngine
6. **Генерируется TLDR** в формате LONGFORM
7. **Пользователь получает** структурированный анализ

### **Fallback логика:**
- Если MCP недоступен → используется обычный YouTube процессор
- Если MCP не может получить транскрипт → показывается ошибка
- Если SummaryEngine недоступен → показывается базовый ответ

## 🔧 **Технические детали**

### **Поддерживаемые URL форматы:**
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/live/VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`

### **Обработка ошибок:**
- Неверный URL
- MCP сервис недоступен
- Транскрипт не найден
- Ошибки SummaryEngine

### **Интеграция с существующей системой:**
- Использует существующий `chat_last_messages` для хранения
- Интегрируется с командами `/transcript`, `/summary`
- Поддерживает все существующие функции бота
