# Активный контекст: Внедрение двухрежимного саммари-движка

## 🎯 Текущая задача
Внедрение двухрежимного саммари-движка TLDRBuddy в существующий Telegram Voice-to-Insight Pipeline

## 📊 Анализ текущей архитектуры

### Существующие обработчики:
1. **Voice messages** (`@dp.message(F.voice)`) - строки 596-750
2. **Video notes** (`@dp.message(F.video_note)`) - строки 723-850
3. **Text messages** (`@dp.message(F.text & ~F.command)`) - после строки 850

### Текущий flow:
1. Получение файла → `speech_pipeline.process_voice_message()`
2. Транскрипция → `text_processor.process_parallel()`
3. Форматирование → `text_processor.format_output()`
4. Отправка результата пользователю

### Ключевые компоненты:
- `SpeechPipeline` - обработка аудио/видео
- `TextProcessor` - анализ текста через режимы (DEFAULT, TONE)
- `ButtonUIManager` - управление кнопками
- `ArchetypeSystem` - система архетипов для советов

## 🔄 Планируемые изменения

### Новые типы источников для поддержки:
- `telegram_document` - документы (PDF, DOC, etc.)
- `video` - обычные видео файлы (не video_note)
- `uploaded_url` - внешние ссылки на контент

### Новые режимы обработки:
- **CHAT** - для коротких сообщений (текущий функционал)
- **LONGFORM** - для длинного контента (новый функционал)

### Точки интеграции:
1. **Новые обработчики сообщений** для document/video/URL
2. **Роутинг логика** для определения режима
3. **Расширение TextProcessor** для поддержки LONGFORM режима
4. **Новые промпты** для каждого режима

## 🛡️ Стратегия безопасного внедрения

### Принципы:
1. **Обратная совместимость** - текущие обработчики остаются без изменений
2. **Feature flags** - возможность включения/отключения нового функционала
3. **Поэтапное развертывание** - сначала тестирование, потом продакшн
4. **Fallback механизмы** - при ошибках возврат к текущей логике

### План миграции:
1. **Этап 1**: Создание SummaryEngine как отдельного модуля
2. **Этап 2**: Добавление новых обработчиков с feature flag
3. **Этап 3**: Интеграция с существующим TextProcessor
4. **Этап 4**: Тестирование и валидация
5. **Этап 5**: Полное развертывание
