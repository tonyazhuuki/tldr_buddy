### 🤖 Этап 2: Тестовый бот (Рекомендуется)

#### 2.1 Создание тестового бота
1. Откройте @BotFather в Telegram
2. Создайте нового бота: `/newbot`
3. Назовите его "TLDRBuddy Test Bot"
4. Получите токен и добавьте в `.env`:

```bash
# Добавьте в .env файл
TEST_TELEGRAM_TOKEN=your_test_bot_token_here
```

#### 2.2 Запуск тестового бота
```bash
# В отдельном терминале
python test_bot_tldrbuddy.py
```

#### 2.3 Тестирование через Telegram
1. Найдите вашего тестового бота в Telegram
2. Отправьте `/start`
3. Выполните команды по порядку:
   ```
   /init          # Инициализация
   /test_summary  # Тест SummaryEngine
   /test_mode     # Тест режимов
   /test_fallback # Тест fallback
   /status        # Проверка статуса
   /results       # Результаты тестов
   ```
